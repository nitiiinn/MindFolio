# MINDFOLIO: COMPREHENSIVE PROJECT ARCHITECTURE

## 1. INTRODUCTION AND VISION
MindFolio is a cutting-edge Retrieval-Augmented Generation (RAG) based study assistant and educational platform. Designed to revolutionize the way students, researchers, and professionals interact with lengthy PDF documents, it transforms static text into an interactive, AI-driven learning experience. The core vision of MindFolio is to act as a personalized tutor that not only answers questions instantly but also proactively generates diverse study materials, ensuring comprehensive knowledge retention and minimizing the friction of manual note-taking.

By employing a multi-model architecture, MindFolio intelligently routes different computational tasks to specialized large language models (LLMs) hosted on fast inference engines (Groq) and highly accurate providers (Mistral AI). This guarantees a seamless, real-time user experience while maintaining the highest standards of factual accuracy.

---

## 2. DETAILED CORE FUNCTIONALITIES

### 2.1 Multi-Document Ingestion and Processing Pipeline
MindFolio goes beyond simple single-file uploads. Users can upload an entire library of PDF documents simultaneously. 
- **Parsing and Extraction:** The application securely reads the uploaded PDFs, extracting raw text while maintaining the structural integrity of the content.
- **Intelligent Chunking:** The extracted text is passed through semantic text splitters that break the documents down into manageable, overlapping "chunks."
- **Vector Embeddings and Storage:** These chunks are converted into dense vector embeddings using `mistral-embed` and stored in a local ChromaDB vector store. This enables lightning-fast, mathematically precise similarity searches.

### 2.2 Real-Time Conversational Chat (Q&A)
At the heart of the application is a conversational interface with memory.
- **Contextual Memory:** When a user asks a follow-up question (e.g., "Can you summarize it?"), an AI query rewriter resolves the pronouns using the chat history before searching the database.
- **Semantic Retrieval:** The system retrieves the most relevant text chunks from ChromaDB.
- **Instant Generation:** Powered by Groq's custom LPU hardware, the answer is generated instantly.
- **Source Transparency:** Every response is accompanied by source badges, explicitly showing the user which document the AI derived its answer from.

### 2.3 The AI Hallucination Verifier
To combat the well-known issue of AI hallucinations, MindFolio implements a rigorous secondary "Verifier Layer." 
- Every draft answer generated by the primary Q&A model is intercepted and sent to a massive verification model (`gpt-oss-120b`).
- This verifier cross-references the draft answer strictly against the retrieved document context.
- It calculates a "Hallucination Score". If the draft answer contains unsupported claims, the verifier actively corrects them or flags them before the final answer is presented to the user.

### 2.4 Agentic Internet Search Fallback
MindFolio recognizes that documents are static and sometimes lack real-world examples or external context.
- If a user asks a question outside the scope of the PDFs, or if the verifier detects that the answer cannot be found in the text, the system triggers an intelligent fallback.
- It leverages an agentic AI model (`groq/compound`) that autonomously browses the internet in real-time.
- It extracts live data and returns an answer with a "Web Search" badge, giving the local application infinite knowledge scope.

### 2.5 Automated Generation of Study Artifacts
MindFolio acts as an automated curriculum builder by generating downloadable PDF study materials:
- **Comprehensive Study Notes:** Synthesizes the raw text into a structured, highly detailed textbook-style study guide.
- **MCQ Practice Quizzes:** Intelligently creates a 15-25 question multiple-choice quiz (easy, medium, hard) with detailed answer keys.
- **Flashcards:** Extracts factual recall queries and conceptual definitions to generate 20-30 interactive Q&A flashcards.
- All generated materials are dynamically compiled into beautifully formatted PDFs using ReportLab.

## 3. ADVANCED AI ROUTING AND MODEL ARCHITECTURE
The true power of MindFolio lies in `llm/model.py`, which acts as the "Traffic Controller". Instead of relying on a monolithic model, it routes specific tasks to the most optimal model available based on the need for speed vs. structural accuracy.

### 3.1 Speed-Critical Tasks (Routed to Groq)
Groq utilizes specialized hardware to deliver sub-second inference speeds. All user-facing, real-time chat interactions are routed here:
1. **Core Q&A (Chat):** `llama-3.3-70b-versatile` (Instant, conversational answering).
2. **Query Rewriting:** `llama-3.1-8b-instant` (Lightning-fast pronoun resolution for chat memory).
3. **Chat History Summarization:** `llama-3.1-8b-instant` (Summarizes past messages to save tokens in the main context window).
4. **Verifier Layer:** `openai/gpt-oss-120b` (Massive model used to quickly audit answers for hallucinations).
5. **Internet Search Fallback:** `groq/compound` (Agentic model for rapid web scraping).

### 3.2 Accuracy & Generative Tasks (Routed to Mistral)
Mistral is utilized for the heavier, background generative tasks and embeddings where absolute accuracy, complex reasoning, and specific formatting (like multiple-choice structures) are required.
1. **Document Embeddings:** `mistral-embed` (High-quality vector math for semantic search).
2. **Flashcards Generation:** `ministral-8b-2512` (Strict instruction following for Q&A pairs).
3. **MCQ Quiz Generation:** `ministral-8b-2512` (Ensures diverse question creation without formatting breaks).
4. **Study Notes Generation:** `open-mistral-nemo` (Synthesizes massive amounts of text into coherent educational narratives).

### 3.3 Concurrency and Optimization
To ensure the chat feels instantaneous, MindFolio utilizes Python's `ThreadPoolExecutor`. When a user sends a message, the system **simultaneously** searches the vector database and summarizes the chat history on parallel threads. By the time the search is complete, the history is ready, halving the perceived wait time.

## 4. TECHNOLOGY STACK AND INFRASTRUCTURE

### 4.1 Frontend Architecture
- **Streamlit:** Powers the entirely of the web-based graphical user interface. 
- **Custom CSS:** The frontend is heavily customized using raw CSS injected into the app. This includes modern typography, dynamic hover effects, and custom chat bubbles.

### 4.2 Backend & Orchestration
- **LangChain:** The overarching framework used to orchestrate the RAG pipeline. It manages the flow of data between the document loaders, text splitters, vector stores, and the LLMs.
- **ChromaDB:** A high-performance, open-source vector database used to store the numerical representations (embeddings) of the PDF chunks.

### 4.3 Utilities
- **PyPDF:** Utilized in the ingestion phase for robust extraction of text from uploaded PDFs.
- **ReportLab:** A powerful PDF generation library used programmatically to construct the final downloadable Study Notes, Quizzes, and Flashcards.
